# Sales-Trend-Analysis-Using-Aggregations-

Sales Trend Analysis Using SQL Aggregations
Objective
The goal of this project is to analyze monthly revenue and order volume using SQL aggregation techniques. This helps identify business trends and seasonal performance patterns.

Tools Used
MySQL (query can be adapted to PostgreSQL or SQLite)

SQL for data manipulation and analysis

Simulated dataset containing sales data including order dates, revenue amounts, and product information

Dataset Overview
The dataset used contains the following columns:

Order ID

Order Date

Amount

Product ID

It includes sample sales transactions spread across several months to allow for meaningful time-based trend analysis.

Analysis Summary
The data is grouped by year and month to calculate:

Total revenue for each month

Total number of unique orders per month

Sorting is done chronologically to observe sales trends over time.

Results
The analysis provides a monthly breakdown of:

Revenue performance

Order volume trends

This allows for better business decision-making based on sales cycles, seasonal peaks, and underperforming periods.
